# Design brief — FrameBuilding

**Name (exact):** FrameBuilding — one word, internal capital B. Set on site as Frame*Building* (roman + italic).
**By:** Amiraé Studio. Predecessor product: FrameCity (200+ buildings modelled).
**What it is:** Hand-modelled landmark buildings, engineered for a perfect 3D print. Pick a building → style the
base in the Studio (plinths, engraving, finishes) → print it for your shelf. Launched on MakerWorld, tested on
Bambu Lab printers.
**Audience:** 3D-printing makers (Bambu Lab owners), architecture lovers, collectors, gift buyers.
**Brand adjectives:** crafted (hand-rebuilt, never a scan dump) · precise/engineered · architectural · editorial
(Fraunces/Newsreader, muted violet + rose) · collectible.
**Promise:** Real architecture, every cornice and arch, surviving the size you actually print.
**Competition / category:** MakerWorld–Printables–Thingiverse model brands, miniature architecture and
model-kit brands.
**Palette on hand:** violet #6468ab, rose #d97f92, cream #f6eaea, ink #4a4344, paper #f8f8fa.
**Must work:** 16 px favicon, nav at ~28 px beside the wordmark, dark and light sections, one colour,
printed/embossed on a model base.

## Category clichés — off limits
Skyline silhouettes · isometric cubes and layer-cake stacks · printer nozzles and filament spools · house
outlines · blueprint grids · a single famous building drawn literally · an F in a rounded square.

## Also off limits here
Everything the current mark does, since this is a clean break: square frame brackets, a tower built from stacked
rectangles, a detached base bar under the building.

## Word map
Frame → viewfinder, framing (construction), armature, crop, scaffold, chassis, section cut
Building → facade, cornice, arch, arcade, dome, drum, lantern, course, elevation, landmark
Printing → layer, course, slice, strata, build plate, growth, extrusion
**Intersections:** *course* (a masonry layer AND a print layer) · *section* (an architect's cut AND a slice) ·
*built in horizontal rings* (true of a masonry dome and of every FDM print).

## Assumptions
Mark must stand alone from the wordmark (favicon, model base, MakerWorld avatar). One or two colours.
Keeping the existing violet/rose family so the site needs no repaint, unless told otherwise.

## Note
The skill's reference library ships metadata only (no SVG files on this machine), so I studied the category from
its classifications plus my own knowledge rather than reading reference geometry.
